🏡 Real Estate Platform (MERN Stack)

A modern responsive real estate web application where users can search properties, save favorites, shortlist them, view locations on map, and directly communicate with property owners.

This platform is designed to provide a seamless experience for property buyers and sellers without any middleman.

🚀 Features

- Search properties based on location, price, and category
- Save favorite properties
- Shortlist properties for later decision
- View property locations on map
- Direct communication with property owners
- Fully responsive design (mobile, tablet, desktop)
- Secure authentication system

🧪 Installation

🔁 Clone the Repository

git clone https://github.com/AyushPatil2223/Real_Estate.git
cd real-estate-app

📂 Environment Variables

Create .env file in server folder:
```env
MONGO_URI=
JWT_SECRET=
CLOUDINARY_URL=
GOOGLE_MAPS_API_KEY=
```
